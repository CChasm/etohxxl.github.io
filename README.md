#### Commands:

# Pressing **F2** allows you to open the **command bar**.
# Inside the **command bar** you can type one of the following **commands**:

## - kick:
#   **Parameters:** Players? -> *player_name* or *set_of_players*
#   **Alias:** 'boot'
#   **Description:** *Kicks* a selected `@Players` player or set of players.
